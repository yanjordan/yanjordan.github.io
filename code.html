Code

Code from my papers, plus tools I keep coming back to. Most of it is research code: usable, but written for a purpose rather than for a product.

Python

  • D2AF

    Distortion distribution analysis by fragmentation - decomposes distortion energy to individual atoms and produces a distortion map.

    GitHub PyPI DOI

    Used in: Chem. Sci. 2025, 16, 2351-2362

  • ECHG

    Python GUI for electron charge density maps (a port of the earlier MATLAB GUI).

    GitHub

  • Pymol_scripts

    Helper scripts for PyMOL, mostly for setting up and inspecting QM/MM models.

    GitHub

Fortran

  • ONIOM_QR_mod

    ONIOM-based quantum refinement code for metalloproteins and protein-drug systems.

    GitHub DOI

    Used in: J. Chem. Theory Comput. 2021, 17, 3783-3796; Nat. Commun. 2024, 15, 4181

  • QT_Polyrate17_Gaussrate17_Mod

    Modified Polyrate / Gaussrate for tunnelling rate calculations under an external electric field.

    GitHub DOI

    Used in: J. Phys. Chem. Lett. 2023, 14, 1124-1132

  • Cluster_Model_Cry14

    Cluster model for computing density matrices and related properties from CRYSTAL14 output.

    GitHub DOI

    Used in: J. Chem. Phys. 2018, 148, 164106; Acta Cryst. A 2018, 74, 131-142

MATLAB

  • MATLAB_GUI_ED

    GUI for electron density maps (CRYSTAL, Gaussian), density matrices, Moyal functions, Compton profiles and momentum density reconstruction.

    GitHub

Gaussian utilities

  • Gaussian_ext

    External interfaces from Gaussian to other programs, plus assorted tools for Gaussian calculations.

    GitHub
